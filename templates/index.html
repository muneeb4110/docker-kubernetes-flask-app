Load balancing test

Each click sends many requests. Every bar is one pod and its length is how many requests that pod answered. With 2 or more replicas you should see more than one bar.

How this page works

  1. Your browser opens / and Flask returns this HTML page.
  2. app.js calls /api/info to ask which pod is answering, and /health to check the app is healthy.
  3. In Kubernetes, the Service sends each new request to one of the running pods, so the pod name can change between requests.
  4. The version is built into the Docker image, and the environment name comes from the Kubernetes ConfigMap.
